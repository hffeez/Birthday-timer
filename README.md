# 🎂 Birthday Countdown

A clean, minimalist web app that counts down the days, hours, minutes, and seconds until your next birthday.

## Features

- Enter your name and date of birth
- Live countdown in days, hours, minutes, and seconds
- Shows your next birthday date
- Shows which age you are turning
- Special message when your birthday is close or today

## Built With

- HTML
- CSS
- JavaScript

## How to Use

1. Open the app
2. Type your name
3. Select your date of birth
4. Click **Start Countdown**
5. Watch the timer count down in real time
