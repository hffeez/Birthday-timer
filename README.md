# 🎂 Birthday Countdown

Find out exactly how long until your next birthday.

## Features

- Enter your name and date of birth
- Live countdown in days, hours, minutes and seconds
- Shows your next birthday date
- Shows which age you are turning
- Special message when birthday is close or today

## Built With

- HTML
- CSS
- JavaScript

## How to Use

1. Enter your name
2. Select your date of birth
3. Click Start Countdown
4. Watch the timer count down in real time
